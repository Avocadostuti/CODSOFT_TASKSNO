
# Task 3 - ATM Interface

## Description
This project is a simple ATM Interface
developed using Java.

It allows users to:
- Withdraw money
- Deposit money
- Check account balance
- Exit the ATM system

## Classes Used

1. ATM.java
   - Displays the ATM menu.
   - Handles user choices.
   - Performs ATM operations.

2. BankAccount.java
   - Stores the account balance.
   - Handles deposits and withdrawals.
   - Checks the current balance.

## Features
- User-friendly menu.
- Input validation.
- Insufficient balance checking.
- Transaction success and failure messages.

## Technologies Used
- Java
- Object-Oriented Programming

## How to Run
1. Compile both Java files:
   javac ATM.java BankAccount.java

2. Run the program:
   java ATM
