# CODSOFT Java Development Internship

## Task 2: Student Grade Calculator

### Project Description
The Student Grade Calculator is a Java-based console application developed as part of the CODSOFT Java Development Internship.

The program accepts marks obtained by a student in different subjects, calculates the total marks and average percentage, and assigns a grade based on the student's performance.

### Features
- Accepts marks for multiple subjects.
- Calculates total marks obtained.
- Calculates average percentage.
- Assigns grades based on average percentage.
- Displays total marks, percentage, and final grade.
- Validates user input to ensure marks are within the valid range.

### Technologies Used
- Java
- VS Code
- Java Scanner Class

### How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open `StudentGradeCalculator.java`.
4. Open the terminal in VS Code.
5. Compile the program:

   `javac StudentGradeCalculator.java`

6. Run the program:

   `java StudentGradeCalculator`

7. Enter marks when prompted.

### Sample Output

```

Total Marks: [Calculated Total]
Average Percentage: 85.00%
Grade: A
```
