## Task 1: Number Game

### Project Description
The Number Game is a Java-based console application developed as part of the CODSOFT Java Development Internship.

The program generates a random number between 1 and 100, and the user has to guess the correct number within a limited number of attempts.

### Features
- Random number generation between 1 and 100.
- User input using Scanner.
- Feedback for guesses that are too high or too low.
- Maximum of 7 attempts per round.
- Multiple rounds of gameplay.
- Option to replay the game.
- Score tracking.
- Final game statistics.

### Technologies Used
- Java
- VS Code
- Java Scanner Class
- Java Random Class

### How to Run
1. Install Java JDK.
2. Open the project in VS Code.
3. Open `NumberGame.java`.
4. Run the Java program.
5. Follow the instructions displayed in the terminal.
